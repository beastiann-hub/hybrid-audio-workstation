# 🎛️ Effects & Recording System Guide

## 📍 **Where to Find Effects:**

### 🎚️ **Live Effects (Always Available)**
**Location:** Left sidebar below performance pads
- **Reverb slider** - Immediate reverb control
- **Delay slider** - Real-time delay effect
- **Filter slider** - Frequency filtering

### 🎛️ **Master Effects (Mix Workflow)**
**Location:** Mix workflow tab → Master Effects panel
- **Master Reverb** - Global reverb control with percentage display
- **Master Delay** - Global delay with visual feedback  
- **Master Filter** - Frequency filter control
- **Master Compressor** - Dynamic range compression
- **Preset buttons:** DRY, AMB, SPC, HLL for instant effect settings

**How to access:**
1. Click the **🎛️ Mix** workflow tab
2. Scroll down to see the **Master Effects** panel
3. Use sliders for real-time control or preset buttons for instant settings

## 🎤 **Where to Find Recording System:**

### ⏺️ **Main Recording (Capture Workflow)**
**Location:** Capture workflow tab → Recording Laboratory panel
- **Record Arm** (🔴) - Arms recording system
- **Monitor Toggle** (🎧) - Live input monitoring
- **Input Gain slider** - Microphone level control
- **Overdub Mode** (🎵) - Layer recordings

### 🔄 **Loop Recording (New!)**
**Location:** Capture workflow → Loop Recording panel (auto-generated)
- **Loop Record** (🔄) - Start loop recording
- **Loop Clear** (🗑️) - Clear current loop  
- **Loop Export** (💾) - Export loop to tracks/samples
- **Loop Length** - Set recording length in beats (1-32)

**How to access:**
1. Click **⏺️ Capture** workflow tab
2. See Recording Laboratory for basic recording
3. Scroll down for Loop Recording panel

## 🔄 **Loop Recording Functionality - YES!**

### ✅ **Complete Loop System Added:**

#### **🎛️ Loop Controls:**
- **Loop Length Setting** - Choose 1-32 beats per loop
- **Auto-Length Calculation** - Based on current BPM
- **Visual Feedback** - Active button states and status messages

#### **🔄 Recording Modes:**
1. **Standard Loop** - Records for set duration, then plays back infinitely
2. **Overdub Mode** - Layer additional recordings on top of existing loop
3. **Auto-Export** - Automatically saves loops to tracks or sample bank

#### **⚡ Smart Features:**
- **Beat-Sync Recording** - Loops align perfectly with your BPM
- **Auto-Playback** - Recorded loops start playing immediately  
- **Mix & Layer** - Overdub mode mixes new recordings with existing loop
- **Export Options** - Save loops to tracks or sample bank for further use

### 🎯 **How to Use Loop Recording:**

1. **Setup:**
   - Go to **⏺️ Capture** workflow
   - Set **Loop Length** (4 beats is default)
   - Enable **Overdub Mode** if you want to layer

2. **Record:**
   - Click **🔄 Loop Record** to start
   - Record your audio (automatic stop after loop length)
   - Loop immediately starts playing back

3. **Layer (Overdub):**
   - With overdub mode ON, click **🔄 Loop Record** again
   - New recording layers with existing loop
   - Repeat for multiple layers

4. **Export:**
   - Click **💾 Loop Export** to save to tracks/samples
   - Or use **🗑️ Loop Clear** to start over

## 🎵 **Complete Audio Workflow:**

### **Performance → Capture → Chop → Mix**

1. **🎹 Performance:** Play live with effects (sidebar controls)
2. **⏺️ Capture:** Record audio/loops with monitoring
3. **🔪 Chop:** Slice recorded audio into samples
4. **🎛️ Mix:** Apply master effects and final mixdown

### **Available Effects Throughout:**
- **Live Effects** - Always accessible in sidebar
- **Master Effects** - Global control in Mix workflow  
- **Preset System** - Instant effect configurations
- **Real-time Control** - All effects respond immediately

## 🚀 **Quick Start Examples:**

### **🔄 Create a Beat Loop:**
1. Capture workflow → Set 4 beats → Loop Record → Beatbox a rhythm → Auto-plays
2. Overdub mode ON → Loop Record again → Add bass line → Layers automatically

### **🎛️ Apply Effects:**
1. Use sidebar sliders for immediate effects during performance
2. Or Mix workflow → Master Effects → Use presets (AMB for ambient, SPC for space)

### **💾 Full Production:**
1. Record loops in Capture → Export to tracks
2. Chop samples → Send slices to sequencer  
3. Mix workflow → Master effects → Final mixdown
